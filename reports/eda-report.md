## 2. 类别分布结论

10 个类别共 62,752 条评论。样本最多的类别是「平板」（10,000 条，占 15.94%），最少的是「热水器」（574 条，占 0.91%），最大与最小之比为 17.4:1，属于明显的类别不均衡。Accuracy 对本任务的小类完全不敏感：即使模型彻底忽略只占 0.91% 的「热水器」，整体 Accuracy 的下降也不到 0.9%，模型仍可能看起来「表现良好」。因此本项目以验证集 Macro-F1 作为主要选模指标，同时报告每类的 precision / recall / F1 与混淆矩阵，确保少数类的表现不被平均掉。

## 3. 类别内情感分布结论

整体情感分布接近均衡：正向 50.56%、负向 49.44%。但类别之间差异明显：「热水器」的正向占比为 82.58%，正负样本严重倾斜；而「平板」的正向占比为 50.00%，接近均衡。这意味着扩展任务（情感二分类）的难度在不同类别上并不一致，评估时必须按类别分别查看召回率，不能只看整体指标；同时提示「热水器」类别的情感标签可能受采集方式影响，需要在报告中如实说明。

## 4. 文本长度结论

评论长度呈典型的长尾分布：中位数 34 字符，平均值 58.4，95% 分位 183，99% 分位 374，最长 2,876 字符。分布高度右偏，说明少数超长评论会把平均值拉高，决策时应优先参考中位数和分位数而不是平均值。

各类别的长度中位数差异明显：「书籍」最长（145 字符），「热水器」最短（22 字符）。所有类别都存在超长尾部，说明长度差异是类别间的固有差异，截断策略必须对所有类别采用统一长度，不能按类别分别截断，否则会让短文本类别在特征上获得不公平优势。

## 5. 数据清洗前后对比结论

清洗前 62,774 条，清洗后 62,752 条，合计删除 22 条（0.0350%）。删除量最大的是「deduplicate_within_category」（19 条），具体为：drop_missing_or_blank 删除 1 条、drop_meaningless_text 删除 2 条、deduplicate_within_category 删除 19 条。删除比例低于千分之一，对类别分布和样本规模没有实质影响；另有 796 条文本仅被修正（控制字符、HTML 实体、空白归一化）而未被删除，这一类「修复而非丢弃」的处理保留了有效样本，是本流程的关键取舍。

## 6. 分词与词云分析

分词方式：jieba 精确模式。停用词过滤规则：过滤长度小于 2 的词、110 个中文停用词，以及既不含中文也不含拉丁字母的纯标点或纯数字串。
统计范围：**训练集**，与后续 TF-IDF 特征拟合的口径保持一致，
避免任何测试集信息影响特征工程决策。

### 6.1 整体词云

对训练集评论做 jieba 精确模式分词并过滤停用词后，出现次数最高的词依次为：不错（12,215 次）、酒店（8,970 次）、京东（6,997 次）、房间（6,441 次）、服务（4,090 次）、质量（4,081 次）、苹果（3,856 次）、喜欢（3,687 次）、价格（3,056 次）、满意（2,697 次）。共统计到 200 个有效词进入词云。词云只能反映词频高低，无法体现词的分布差异，因此它只作为语料特征的直观展示，不参与任何特征选择或模型决策；定量的高频词统计见下一节的各类别高频词对比图。

### 6.2 各类别高频词

各类别高频词分布如下：酒店→「酒店」、水果→「苹果」、书籍→「本书」、手机→「功能」、蒙牛→「蒙牛」、热水器→「安装」 等词只出现在单一类别的 Top-15 中，带有明确的领域或品类特征，对类别判定有直接指示作用。与此相对，「不错」（10/10 个类别的 Top-N）、「收到」（5/10 个类别的 Top-N） 等评价类词会同时进入多数类别的高频词表，属于跨类别的通用评价语言，区分能力很弱。这一对比对后续 TF-IDF 特征工程有直接指导意义：通用评价词在各类别中的分布接近，TF-IDF 的 IDF 项本应自动压低它们的权重，但若其在文档中占比过高仍会稀释有效特征；因此特征工程阶段需要检查这类词的实际权重，必要时补充进停用词表。需注意本图只统计词频，未考虑词在类别间的相对分布，定量结论以 TF-IDF 权重诊断为准。

## 7. BERT 候选 max_length 评审

以字符长度近似 token 长度（中文 BERT 的词表对汉字基本一字一 token），max_length=128 可完整覆盖 89.73% 的评论，max_length=256 可覆盖 97.88%。覆盖率随长度增加而快速趋缓，说明继续加长收益有限但计算成本线性上升。

### 7.1 覆盖率明细

| 候选 max_length | 完整保留占比 | 被截断占比 | 被截断样本数 |
| ---: | ---: | ---: | ---: |
| 32 | 47.03% | 52.97% | 26,596 |
| 64 | 75.16% | 24.84% | 12,470 |
| 96 | 85.18% | 14.82% | 7,441 |
| 128 | 89.73% | 10.27% | 5,154 |
| 160 | 92.57% | 7.43% | 3,728 |
| 192 | 96.16% | 3.84% | 1,926 |
| 256 | 97.88% | 2.12% | 1,064 |
| 384 | 99.05% | 0.95% | 477 |
| 512 | 99.51% | 0.49% | 247 |

### 7.2 结论与建议

**不能照搬原投满分项目的 `max_len=32`。** 本数据集的评论文本远长于新闻标题：`max_length=32` 只能完整保留 47.03% 的评论，会截断 26,596 条（52.97%）样本，超过一半的评论文本信息会被丢弃，其中包含大量判断类别和情感的关键描述。

- **推荐默认值 `max_length=128`**：完整保留 89.73% 的训练样本，只截断 5,154 条；在覆盖率与显存/耗时之间最平衡。
- **高覆盖备选 `max_length=256`**：完整保留 97.88%，截断量降到 1,064 条，代价是注意力计算量显著上升。
- **95% 覆盖率下限**：满足该标准的最小候选值是 `max_length=192`（覆盖率 96.16%）。
- 训练时应记录实际使用的 max_length，并在评估报告中与本节结论对应；若显存不足而必须下调，需说明下调后新增的截断比例，不能静默修改。
- 训练集规模为 50,206 条，以上覆盖率均在训练集上统计，验证集与测试集必须使用同一 max_length，以保证评估公平。

### 7.3 本评审的局限

- 上表用**字符长度**近似 token 长度。中文 BERT 的 WordPiece 词表对汉字基本是一字一 token，
  因此该近似在中文评论上偏差很小，但仍是近似值。
- 本项目当前环境无法下载预训练分词器，因此未能用真实 tokenizer 复核。
  在 BERT 阶段拿到本地分词器后，必须用真实 token 长度重新计算一次覆盖率，
  并把结果补充到本节；在此之前，本节的数字应标注为「字符长度近似」。
