## 一、总体目标

在最终答辩前准备一套可现场运行、可播放录屏、可退化为静态讲解的演示材料。所有截图、视频、指标和案例必须来自项目真实运行结果，不得使用概念图中的示例数字代替实验结果。

材料统一放在：

```text
reports/final-presentation/
├── screenshots/                 # 最终采用的系统与结果截图
├── videos/                      # 核心演示和异常处理录屏
├── member-assets/
│   ├── humingchang/             # 数据、传统模型、情感基线材料
│   └── hongsenyuan/             # FastText、BERT、优化材料
├── task-assignment.md           # 本任务分工
└── README.md                    # 最终答辩材料索引
```

模型权重、原始数据、缓存和本地环境文件不得放入上述目录或提交 Git。

## 二、全组共同要求

1. 所有指标必须引用仓库内真实的 `metrics.json`、结果 JSON 或报告，不得估算或编造。
2. 截图必须来自实际运行；图片中需能辨认标题、字段和关键数值。
3. 录屏不得出现密码、Token、API Key、个人聊天、无关桌面通知或隐私信息。
4. 每段录屏完成后必须从头播放检查声音、画面、文字和操作是否完整。
5. 不提交大型模型、训练缓存、原始 CSV 和临时录制工程文件。
6. 每位成员只修改自己的 `member-assets/<姓名>/` 内容；公共 PPT、总讲稿和 Web 代码由 LanQvJian 统一集成。
7. 未完成或未验证的功能必须如实标注，不得包装成已经实现。
